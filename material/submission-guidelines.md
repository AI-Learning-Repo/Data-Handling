# Submission Guidelines (Google Drive)

Please follow the instructions below to set up a shared Google Drive folder for submitting your weekly activities and assignments.

---

#### **1. Initial Folder Setup (Do this once)**
1. Open [Google Drive](https://drive.google.com).
2. Create a new folder named: `[Your  Name] - [Group Number]`.
3. Inside your main folder, create subfolders for each week (e.g., `Week 1`, `Week 2`, `Week 3`, etc.).

---

#### **2. Sharing the Folder**
1. Right-click on your **main folder** and select **Share**.
2. Enter the following email address: **ml.course.2025@gmail.com**
3. Set the access permission to **Viewer**.
4. Click **Send**.

> *Note: You only need to share the main folder once. Any subfolders or files added later will automatically be visible.*

---

#### **3. Submitting Weekly Activities**
* Place all completed work into the corresponding week’s subfolder (e.g., all Week 2 activities should be uploaded to the `Week 2` folder).

---

#### **4. Group Assignments**
* For group assignments, choose **one member** of the group to host the file.
* Upload the assignment into the appropriate week's subfolder within that member's already-shared folder.
* **Important:** Ensure all group members’ names are clearly listed at the top of the submitted document. There is no need to create or share a separate folder for group work.
