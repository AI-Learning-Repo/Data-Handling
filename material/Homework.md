# Homework: NumPy, Pandas, and Matplotlib

## Overview

This homework is an introduction to three essential Python libraries for data science:

1. **NumPy** - numerical computing and working with arrays
2. **Pandas** - data manipulation and preparation
3. **Matplotlib** - data visualization

For each topic, **watch the video and go through the tutorial/reading** before next week.

You do **not** need to understand or memorize everything at this stage. The goal is to become familiar with the libraries, their main concepts, and the types of tasks they can be used for.

Next week, we will put these concepts into practice using a **real-world dataset and Exploratory Data Analysis (EDA)**. The different concepts will be explained and practiced step by step during the session.
