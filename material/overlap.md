
## Selected questions about data and EDA

EDA means **exploratory data analysis**: examining and understanding data before building a model.

| Questions    | Main overlap                                                                                                    |
| ------------ | --------------------------------------------------------------------------------------------------------------- |
| Q1, Q7, Q9   | Data quality and initial checks. The questions are related and cover different parts of the checking process.   |
| Q3, Q10, Q15 | Understanding data using plots, information about columns and summary statistics.                               |
| Q4, Q15(a)   | Missing data. Q4 focuses on filling missing values, while Q15(a) focuses on finding evidence of missing values. |

Q6 covers converting categories into suitable model inputs. Q13 covers creating useful features. These are separate topics.

## Selected questions about classification

| Questions                      | Main overlap                                                                                                                      |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| Q1, Q24, Q35(a–b)              | Recognizing supervised learning and classification tasks. These questions have similar aims.                                      |
| Q6, Q26, Q35(f)                | Using a simple baseline to judge a model. Q26 also includes a numerical comparison.                                               |
| Q9, Q10, Q11; Q27(a–c); Q35(g) | How classification methods work. Some questions cover similar ideas, while the different methods require different understanding. |
| Q12, Q22, Q35(h)               | Why feature scaling matters. These questions cover much of the same idea.                                                         |
| Q5, Q18, Q25, Q35(e)           | Training data, test data and overfitting. These questions cover related but different aspects of the topic.                       |
| Q13, Q14; Q28(e–f); Q30(a–d)   | Precision and recall. Some questions focus on meaning, while others involve calculations or interpretation.                       |
| Q32, Q33(b–c)                  | The difference between training a model and making predictions. No code writing is required.                                      |

Q35 is a longer question that covers several ideas also found in shorter questions. Some parts of Q35 overlap with those questions.

Q17 and Q29 cover evaluation with several classes. This goes beyond precision and recall for a simple two-class example.

## Selected questions about regression

| Questions                       | Main overlap                                                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Q1, Q5, Q7, Q60                 | Regression tasks and different model forms. Simple, multiple and polynomial regression have different features.                      |
| Q50(a–c), Q61(a, b, d)          | Identifying model inputs and the value being predicted. These parts have similar aims.                                               |
| Q32, Q45, Q54, Q68, Q72; Q60(d) | Model complexity, overfitting and performance on new data. Q54 and Q68 are closely related, while Q72 compares models.               |
| Q25, Q47, Q68(a–b)              | Understanding prediction errors. These questions cover different details, including RMSE units, MAE and the meaning of error values. |
| Q60(c), Q66                     | Polynomial regression. The focus is on the model representation and its meaning, without writing code.                               |

Q11, Q16, Q37 and Q40 cover correlation. They are related but ask different questions. For example, a weak linear correlation and the usefulness of a strongly correlated feature are different issues.

## Selected questions about unsupervised learning

| Questions               | Main overlap                                                                                                                      |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| A2, A3, A4; parts of G1 | Recognizing a clustering task, choosing features and preparing data. G1 includes ideas from the shorter questions.                |
| B1, B2                  | How K-means assigns points to clusters and updates cluster centres. The questions focus on different parts of this process.       |
| C2, G1(d)               | Choosing the number of clusters. These questions have similar aims.                                                               |
| C5, C6, G1(e)           | Checking clustering results. Repeating results, checking stability and explaining cluster profiles are different types of checks. |
| D4, G2                  | Hierarchical clustering. Reading a dendrogram and choosing a clustering method are related but different skills.                  |

E3 and E5 both cover anomaly detection, but from different perspectives. E3 covers anomaly scores and thresholds, while E5 covers checking flagged cases against known labels. Both ideas are relevant.
